2. 動画のアップロード

動画保存用フォルダ直下のフォルダを1つ選んで、YouTube にアップロードします。

初回や「invalid_grant」「403 Insufficient Permission」が出た場合は、先にYouTube 認証を行うを実行してください。ブラウザで Google にログインし、「許可」でアップロード権限を付与するとアップロードできるようになります。

simple は互換性重視、resumable は大きい動画向け、auto は必要時のみ simple に切り替えます。

オン（既定）: ローカルの一覧だけで判定し、すぐ処理を開始します。オフ: 起動時に YouTube API で一覧を取得します（時間がかかりますが、他端末でアップロードした分も反映しやすいです）。

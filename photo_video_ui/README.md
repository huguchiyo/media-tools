# 写真・動画ツール 統合UI

写真と動画の分離（VideoMoveTools）と YouTube へのアップロードを、ブラウザから実行するための Web UI です。

## 必要なもの

- Python 3
- Flask（`pip install -r requirements.txt`）
- 同一の `Tools` 配下にある **VideoMoveTools** と **youtube** の各スクリプト

## 起動方法

### ワンタッチで起動（おすすめ）

- **エクスプローラー**: `Tools/photo_video_ui/start_server.bat` を**ダブルクリック**。数秒後にブラウザが自動で開きます。
- **Cursor / VS Code**: メニュー **ターミナル → タスクの実行** で **「写真・動画ツール サーバー起動」** を選ぶ。その後ブラウザで http://127.0.0.1:5151 を開く。

### 手動でコマンドを打つ場合

```bash
cd Tools/photo_video_ui
pip install -r requirements.txt
python app.py
```

ブラウザで **http://127.0.0.1:5151** を開いてください。

## 機能

1. **設定（歯車アイコン）**
   - ソースフォルダ（camera）・移動先フォルダ（movie）を設定
   - 「参照」でネイティブのフォルダ選択ダイアログを表示（要・ディスプレイのある環境）
   - 設定は `data/settings.json` に保存されます

2. **写真と動画の分離**
   - 設定で指定したソース → 移動先で、`move_videos_to_movie.py` を実行
   - 実行中はログをリアルタイム表示。完了後に「分離結果」を表示

3. **動画のアップロード**
   - **初回または「invalid_grant」エラー時**: 「YouTube 認証を行う」をクリック。トークンをリセットしたうえで認証用の処理が走り、ブラウザが開くので Google でログインし、権限を許可する。完了したら「閉じる」を押し、あらためてアップロードを実行する。
   - movie 直下のフォルダを1つ選択し、アップロード実行
   - 実行中はログをリアルタイム表示。完了後にサマリと詳細（成功・スキップ・失敗一覧）を表示

## フォルダ構成

```
Tools/photo_video_ui/
├── app.py              # Flask バックエンド
├── requirements.txt
├── README.md
├── data/
│   └── settings.json   # 設定（自動生成）
└── static/
    └── index.html      # フロント
```

## 注意

- フォルダ選択ダイアログは **tkinter** を使用しています。サーバーを起動したマシンにディスプレイがある必要があります（リモートの CUI のみの環境では「参照」は使えません）。
- 分離・アップロードは実際にファイルを移動／アップロードします。実行前に確認ダイアログで内容を確認してください。
